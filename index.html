⚙️ System Architecture & Dual-Layer Implementation

AegisSSH combines a Kali Linux Python Backend (detector.py) for live server protection with this Web SOC Dashboard for interactive log auditing and simulation.

1. Live Journal Ingestion

Connects directly to Linux's systemd journal (journalctl -u ssh -f) in real time, eliminating dependency on legacy static text logs.

2. Regex & Sliding Window

Extracts source IP addresses and usernames using Regular Expressions, tracking attempt timestamps inside a 60-second sliding window to prevent false positives.

3. Severity & Firewall IPS

Elevates attacks targeting root or admin to CRITICAL, sends desktop pop-up alerts, logs CSV forensics, and executes iptables DROP rules.

🎓 Project Overview & Use Cases

Problem Solved

Automated bots continuously scan port 22 to guess SSH credentials. Manual log inspection is too slow to stop high-speed dictionary attacks before a breach occurs.

Key Innovations

Features dynamic threshold tuning, Safe Whitelist protection (preventing admin self-lockout), real-time desktop alerts, and one-click IP unblocking.

Real-World Use Cases

Ideal for hardening cloud Linux VPS instances (AWS, Azure, DigitalOcean), university lab servers, and SOC analyst training environments.
